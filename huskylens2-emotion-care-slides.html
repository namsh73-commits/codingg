① 문제 상황

혼자 계신 할머니, 오늘은 괜찮으실까?

문제를 구체적인 장면으로 바꿔 봅시다
김 할머니는 혼자 사십니다. 멀리 사는 손녀는 매일 전화를 드리지만, 할머니는 “괜찮다”고만 하십니다.
그런데 요즘 할머니가 거실에 앉아 오랫동안 슬픈 표정으로 계시거나, 하루 종일 거실에 나오지 않는 날이 있다고 합니다.
손녀가 매 순간 지켜볼 수는 없습니다. 하지만 표정과 움직임의 변화를 알 수 있다면 더 빨리 연락하거나 찾아갈 수 있습니다.

② 자연어 묶음 준비 · 타이머 원리

MakeCode 타이머: “시작 시각”을 기억하기

「실행 시간(ms)」은 micro:bit가 켜진 뒤 흐른 시간입니다 (1초 = 1000ms)
경과 시간 = 실행 시간(ms) − 슬픔시작   →   10000보다 크면 알림
보통 표정
슬픔
보통
슬픈 표정 계속 ……
슬픔시작 = 실행시간4초 만에 끝 → 리셋(0)
슬픔시작 = 실행시간다시 타이머 시작
경과 > 10초 → 알림!“SAD” 전송

세 가지 규칙만 기억하세요

  • 시작 — 슬픔이 처음 보이면(슬픔시작 = 0일 때) 지금 시각을 저장
  • 계산 — 슬픔이 계속되면 지금 − 슬픔시작으로 경과 시간 계산
  • 리셋 — 다른 표정이 나오면 슬픔시작 = 0으로 되돌림

같은 방법으로 “부재 타이머”

  • 얼굴이 보일 때마다 마지막확인 = 지금 시각
  • 얼굴이 안 보이면 지금 − 마지막확인이 30초를 넘는지 확인
  • 수업에서는 10초·30초, 실제로는 수십 분~몇 시간으로 늘려요

② 자연어 묶음

자연어 알고리즘을 4개의 묶음으로

묶음 ① 준비 — 시작하면
01준비I2C 시작, “표정 인식” 선택, 라디오 그룹 1
02저장슬픔시작 = 0, 마지막확인 = 지금 시각
묶음 ② 반복 — 무한반복 실행
03반복계속 반복한다
04입력표정 인식 결과를 가져온다
05판단얼굴이 보이면 → 〔표정 확인〕 묶음 실행
06판단얼굴이 없으면 → 〔부재 확인〕 묶음 실행
묶음 ③ 표정 확인 — 슬픔 타이머
07저장마지막확인 = 지금 시각, e = 가운데 얼굴의 표정 ID
08판단e가 슬픔이면
09저장슬픔시작이 0이면 슬픔시작 = 지금 시각 (타이머 시작)
10판단지금 − 슬픔시작 > 10초 이면
11출력슬픈 아이콘, 소리, 라디오 “SAD”
12저장아니면(웃음·보통) 슬픔시작 = 0 (리셋), 웃는 아이콘
묶음 ④ 부재 확인 — 부재 타이머
13판단지금 − 마지막확인 > 30초 이면
14출력“?” 표시, 라디오 “CHECK”
15출력아니면 LED 지우기

핵심 아이디어

  • 긴 알고리즘은 역할별 묶음으로 나누면 읽기 쉽습니다. 묶음 ③·④는 MakeCode의 함수가 됩니다.
  • 슬픔 표정 ID는 먼저 수 출력 e로 직접 확인하세요. 블록의 6은 예시입니다.
  • 기준 10초·30초도 예시입니다. 측정 → 기준 정하기 → 판단!

테스트 체크리스트

  • ☐ 웃는 얼굴 → 웃는 아이콘, 알림 없음
  • ☐ 슬픈 표정 5초 → 다시 웃기 → 알림 없음 (타이머 리셋 확인)
  • ☐ 슬픈 표정 10초 이상 → 보호자 쪽 Sad + 소리
  • ☐ 카메라 앞에서 30초 이상 사라지기 → 보호자 쪽 “?”
  • ☐ 다시 나타나면 → “CHECK” 멈춤
